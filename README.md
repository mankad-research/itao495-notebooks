# ITAO 495: AI Models and Agents for Business

Colab notebooks, project templates and practice data for **ITAO 495, AI Models and Agents for Business**, an undergraduate course at the NC State University Poole College of Management (Spring 2027).

The notebooks are hands-on labs. You call real language models from code, build small tools and agents, and then test how well they hold up. No coding background is assumed. Notebook 1 sets you up, and Notebook 2 teaches the Python you need.

## Quick start

1. **Open a notebook in Colab.** Click an "Open in Colab" button in the tables below. You need a Google account.
2. **Set up your Groq key once.** Most labs call a model through Groq. Notebook 1 walks you through creating a free API key and storing it in Colab Secrets under the name `GROQ_API_KEY`, with Notebook access turned on. Colab then remembers it for every notebook.
3. **Run the cells from top to bottom.** Click the play button next to a cell or press Shift + Enter. If anything looks stuck, choose **Runtime, then Restart session**, and run again from the top.
4. **Save your own copy.** Colab cannot save changes back to this repository. Use **File, then Save a copy in Drive** to keep your work.

The notebooks are written for Colab's standard free runtime. No GPU is needed.

## Good to know

- **First runs can be slow.** Notebooks 12, 13, 17 and 18, and the Project 2 template, install packages and download small open models (`distilgpt2` and `all-MiniLM-L6-v2`) the first time. Allow a few minutes.
- **Notebook 18 downloads a public filing.** It fetches Apple's 2023 annual report (10-K) when it runs. If the download fails, the notebook tells you how to upload the PDF yourself.
- **Notebook 11b pins an exact version** of the MCP library (`mcp==1.30.0`) so the code keeps working. Leave the pin as it is.
- **Models and limits change.** If you see `model_decommissioned` or a rate-limit error, the troubleshooting table at the end of Notebook 1 explains the fix.

## Keys and safety

- Treat your API key like a password. Keep it in Colab Secrets. Never paste it into a notebook cell, a file or a GitHub commit.
- If a key is ever exposed, delete it at https://console.groq.com and create a new one.
- Notebook 24a and Project 3 involve attacking and auditing AI systems. Use these techniques only on the toy agents and fake data the notebooks provide, and never on real systems, other people's accounts or real personal data.
